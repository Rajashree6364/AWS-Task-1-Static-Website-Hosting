# AWS Task 1: Static Website Hosting

## Project Description
This project demonstrates static website hosting using Amazon EC2, Nginx, and Amazon S3.

## Technologies Used
- Amazon EC2
- Amazon S3
- Nginx Web Server
- Linux (Amazon Linux 2023)
- HTML

## Project Steps
1. Launched an EC2 instance on AWS.
2. Configured security group rules to allow SSH (port 22) and HTTP (port 80).
3. Installed and configured Nginx on EC2.
4. Created a custom static webpage using HTML.
5. Accessed the webpage using the EC2 public IP address.
6. Uploaded `index.html` to Amazon S3 as a backup.

## Project Outcome
Successfully hosted a static website on an EC2 instance using Nginx and stored a backup copy in Amazon S3.
